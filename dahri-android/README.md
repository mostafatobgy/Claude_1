# افهم حالتك — تطبيق أندرويد لفهم الانزلاق الغضروفي

النسخة الأولى فيها قسم **«افهم حالتك»** فقط:

- **مجسم ثلاثي الأبعاد:** أسفل الظهر كاملاً (الفقرات القطنية والأقراص والعجز والعصعص والأعصاب) مع اختيار مكان الانزلاق، ثم نظرة أقرب على قرص واحد يُدار بالإصبع ويُكبَّر باصبعين، ويتغير حسب درجة الانزلاق واتجاهه (المجسم يظهر أيضاً في صفحات الدرجات والاتجاه وحالتي).
- **العمود الفقري:** رسم تفاعلي، المس أي فقرة أو قرص لتعرف اسمه والأعصاب الخارجة منه وما تغذيه.
- **تركيب القرص:** الحلقة الليفية والنواة وجذور الأعصاب (منظر جانبي ومقطع عرضي).
- **درجات الانزلاق:** الانتفاخ والبروز والانبثاق والانفصال، برسم متحرك.
- **اتجاه الانزلاق:** مركزي، خلفي جانبي، داخل الثقب، خارج الثقب، ويتلوّن العصب المضغوط بالأحمر.
- **حالتي أنا:** يُدخل مستوى الانزلاق من تقرير الرنين (مثل L4-L5) فيظهر مكانه والعصب المتأثر عادة.
- **طرق العلاج:** من الأدوية والعلاج الطبيعي والحقن إلى أنواع الجراحات مع رسوم ومدد تعافٍ تقريبية.
- **فيديوهات:** مقاطع محددة من يوتيوب (أطباء عرب وشركات رسوم طبية ثلاثية الأبعاد) مع صورها المصغرة، ومكان لحفظ فيديوهات يرسلها الطبيب.
- **الطوارئ:** علامات متلازمة ذيل الفرس وزر اتصال بالإسعاف.

كل شيء يعمل بدون إنترنت ما عدا الفيديوهات. الرسوم أصلية مرسومة بالكود (SVG)، والمجسم مبني بمكتبة three.js (رخصة MIT، مضمّنة في `lib/`).

## التحميل

بعد كل تعديل يبني GitHub Actions الملف تلقائياً وينشره على رابط ثابت:
https://github.com/mostafatobgy/Claude_1/releases/download/dahri/dahri.apk

## للمطورين

الصفحات في `app/src/main/assets/www/` (HTML وJavaScript بدون مكتبات)، والتطبيق غلاف WebView في
`MainActivity.kt`. للتجربة على الكمبيوتر افتح `index.html` في المتصفح.
