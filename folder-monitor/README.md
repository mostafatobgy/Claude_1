# مراقب أحجام الفولدرات

برنامج صغير لسطح المكتب (Windows / Mac / Linux) يقيس حجم الفولدرات التي تختارها كل فترة،
ويعطيك **تنبيهًا فوريًا** إذا زاد حجم أي فولدر زيادة كبيرة **خلال فترة قصيرة** —
مثل ملف سجل (log) يتضخم، أو برنامج يملأ القرص، أو تحميل لم تكن تعلم به.

## المميزات

- مراقبة أي عدد من الفولدرات (يشمل كل الفولدرات الفرعية).
- تنبيه عند زيادة **بالميجابايت** (مثلًا ≥ 500 MB خلال 10 دقائق) و/أو **بالنسبة المئوية** (مثلًا ≥ 50%).
- يخبرك **أين** حدثت الزيادة: أكثر 3 فولدرات/ملفات فرعية زادت.
- إشعار على سطح المكتب + صوت + إبراز الصف باللون الأحمر في النافذة.
- اختياري: تنبيه على **هاتفك** عبر تطبيق ntfy المجاني (نفس التطبيق المستخدم في تنبيهات الأخبار).
- سجل لكل التنبيهات في `alerts.log`.
- لا يحتاج تثبيت أي مكتبات — Python فقط.

## التشغيل

1. ثبّت [Python 3](https://www.python.org/downloads/) (في Windows فعّل خيار **Add Python to PATH**).
2. شغّل:
   - **Windows:** انقر مرتين على `run-windows.bat`
   - **Mac / Linux:** `python3 gui.py`
3. اضغط **➕ إضافة فولدر** واختر الفولدر، والمراقبة تبدأ تلقائيًا.
4. عدّل الإعدادات أسفل النافذة ثم اضغط **💾 حفظ**.

| الإعداد | المعنى | الافتراضي |
|---|---|---|
| الفحص كل (ثانية) | كم مرة يُقاس الحجم | 60 |
| الفترة القصيرة (دقيقة) | المدة التي تُقارن الزيادة خلالها | 10 |
| نبّهني عند زيادة ≥ (MB) | حد الزيادة بالميجابايت (0 = معطّل) | 500 |
| أو زيادة ≥ (%) | حد الزيادة بالنسبة المئوية (0 = معطّل) | 0 |
| عدم تكرار التنبيه | أقل مدة بين تنبيهين لنفس الفولدر | 15 |

**كيف تُحسب الزيادة:** الحجم الآن ناقص **أصغر** حجم سُجّل خلال «الفترة القصيرة».
الزيادة البطيئة الطبيعية على مدى ساعات لا تسبب تنبيهًا.

## التشغيل بدون نافذة (Terminal)

```bash
cp config.example.json config.json   # ثم عدّل الفولدرات
python3 monitor.py                   # مراقبة مستمرة
python3 monitor.py --once            # طباعة الأحجام مرة واحدة
```

## التشغيل تلقائيًا مع بدء الجهاز (Windows)

اضغط `Win + R` واكتب `shell:startup` ثم ضع داخل الفولدر الذي يفتح **اختصارًا** (Shortcut) لملف `run-windows.bat`.

## تنبيهات على الهاتف (اختياري)

ثبّت تطبيق **ntfy**، اشترك في قناة باسم سري (مثل `folders-` + حروف عشوائية)،
واكتب نفس الاسم في خانة «قناة ntfy» ثم احفظ.

## ملاحظات

- الفولدرات الضخمة جدًا (مئات الآلاف من الملفات) قد يستغرق فحصها وقتًا؛ اجعل «الفحص كل» أكبر لها.
- الملفات/الفولدرات التي لا يملك البرنامج صلاحية قراءتها تُتخطى بدون توقف.
- الاختصارات (symlinks) لا تُتبع حتى لا يُحسب نفس المحتوى مرتين.
