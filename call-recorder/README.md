# مسجّل المكالمات — Call Recorder (Android)

تطبيق أندرويد بسيط وواضح لتسجيل مكالماتك، بلغة Kotlin وواجهة أصلية (Material 3).
يُخزّن التسجيلات على هاتفك فقط — لا خادم ولا رفع ولا حسابات.

## الميزات

- **تسجيل تلقائي:** مُفعّل افتراضيًا — يبدأ التسجيل تلقائيًا بمجرد بدء المكالمة ويتوقف عند انتهائها.
- **تسجيل يدوي:** زر «سجّل الآن» لبدء/إيقاف التسجيل في أي وقت.
- **أسماء جهات الاتصال:** يُطابق رقم المتصل باسمه المحفوظ في جهات الاتصال ويُسمّي التسجيل به.
- **تشغيل داخل التطبيق:** اضغط ▶ للتشغيل ومرة أخرى للإيقاف؛ وإن تعذّر التشغيل داخليًا يُفتح الملف في مشغّل الصوت على الهاتف.
- **إشعار دائم** يوضّح أن التسجيل جارٍ طوال المكالمة — التطبيق شفّاف وليس خفيًّا.
- **قائمة التسجيلات:** تشغيل، مشاركة، وحذف كل تسجيل.
- التسجيلات بصيغة `.m4a` (AAC) في مجلد التطبيق الخاص، وتُحذف عند إزالة التطبيق.

## ملاحظات قانونية وتقنية مهمة

- **القانون مسؤوليتك:** تسجيل المكالمات تحكمه قوانين تختلف بين الدول؛ كثير منها يشترط
  إعلام الطرف الآخر أو موافقته. يعرض التطبيق شاشة موافقة عند أول تشغيل، والمستخدم وحده
  مسؤول عن الاستخدام القانوني.
- **قيود أندرويد:** منذ أندرويد 10 تمنع المنصّة التطبيقات العادية من الوصول إلى صوت الطرف
  الآخر. يحاول التطبيق أفضل مصدر صوت متاح (`VOICE_CALL` ← `VOICE_COMMUNICATION` ← `MIC`)،
  وقد يُسجَّل صوتك أنت فقط على بعض الأجهزة. هذه قيود نظام التشغيل وليست عيبًا في التطبيق.

## الأذونات

| الإذن | السبب |
|------|------|
| `RECORD_AUDIO` | تسجيل صوت المكالمة |
| `READ_PHONE_STATE` | معرفة بدء/انتهاء المكالمة للتسجيل التلقائي |
| `READ_CALL_LOG` | قراءة رقم المتصل لتسمية التسجيل به |
| `READ_CONTACTS` | مطابقة الرقم باسم جهة الاتصال المحفوظة |
| `FOREGROUND_SERVICE` / `FOREGROUND_SERVICE_MICROPHONE` | التسجيل في الخلفية كخدمة ميكروفون ظاهرة |
| `POST_NOTIFICATIONS` | إظهار إشعار «يتم التسجيل» (أندرويد 13+) |

إن لم يتوفّر رقم المتصل (أو عند رفض الإذن) يُحفظ التسجيل باسم «رقم غير معروف».

> **ملاحظة عن التسجيل التلقائي في الخلفية:** منذ أندرويد 12 تُقيّد المنصّة بدء خدمة الميكروفون
> من الخلفية، وقد يمنع بعض المصنّعين التسجيل التلقائي تمامًا. يتعامل التطبيق مع ذلك بأمان (لا
> ينهار)، لكن قد لا يبدأ التسجيل تلقائيًا على كل جهاز؛ في هذه الحالة استخدم زر «سجّل الآن».

## التثبيت

**ملف APK جاهز:** رابط ثابت لأحدث نسخة:
`https://github.com/mostafatobgy/Claude_1/releases/download/recorder/call-recorder.apk`
(ستحتاج السماح بالتثبيت من مصادر غير معروفة.)

**أو من GitHub:** تبويب **Actions ← Build Call Recorder APK ← Run workflow**،
ثم نزّل الملف من صفحة نتيجة التشغيل.

## البناء محليًا

```bash
cd call-recorder
./gradlew assembleDebug
# الناتج: app/build/outputs/apk/debug/app-debug.apk
```

يحتاج JDK 17 و Android SDK (يضبطهما GitHub Actions تلقائيًا في السحابة).
