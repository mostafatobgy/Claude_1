# مراقب الفولدرات — تطبيق أندرويد

يقيس حجم الفولدرات التي تختارها على هاتفك كل بضع دقائق، ويرسل لك **إشعار تنبيه**
إذا زاد حجم أي فولدر زيادة كبيرة **خلال فترة قصيرة** — مثلًا واتساب يحمّل فيديوهات كثيرة،
أو تطبيق يملأ الذاكرة، أو تنزيل لم تكن تعلم به.

## التحميل

رابط ثابت لأحدث نسخة (بعد دمج التعديل في `main`):
https://github.com/mostafatobgy/Claude_1/releases/download/folders/folder-monitor.apk

أو من GitHub: **Actions ← Build Folder Monitor APK ← Run workflow** ثم نزّل الملف من نتيجة التشغيل.
عند التثبيت اسمح بالتثبيت من مصادر غير معروفة.

## الاستخدام

1. افتح التطبيق واضغط الأزرار في البطاقة البرتقالية:
   - **السماح بقراءة أحجام الملفات** — ضروري (يفتح صفحة «الوصول إلى كل الملفات»، فعّلها). التطبيق يقرأ الأحجام فقط ولا يرسل أي شيء خارج الهاتف.
   - **السماح بالإشعارات** — ضروري للتنبيهات.
   - **السماح بالعمل في الخلفية** و**الفحص في الموعد بالضبط** — مستحسنان حتى لا يؤخر نظام توفير البطارية الفحص.
2. اضغط **➕ إضافة فولدر** واختر من الاختصارات (التنزيلات، الكاميرا، واتساب، تيليجرام…) أو تصفّح أي فولدر،
   ثم **✓ راقب هذا الفولدر**. المراقبة تبدأ تلقائيًا.
3. من زر الإعدادات (أعلى اليمين) تحدد:

| الإعداد | الافتراضي |
|---|---|
| نبّهني عند زيادة ≥ (ميجابايت) | 300 |
| خلال فترة (دقيقة) | 30 |
| أو عند زيادة ≥ نسبة % | 0 (معطّل) |
| افحص كل (دقيقة) | 5 |
| لا تكرر التنبيه لنفس الفولدر قبل (دقيقة) | 30 |

كل فولدر يظهر في بطاقة: الحجم الحالي، الزيادة خلال الفترة، وآخر فحص.
عند حدوث زيادة سريعة تصبح البطاقة **حمراء** ويصلك إشعار يذكر **أين** حدثت الزيادة (أكثر 3 ملفات/فولدرات زادت).

## ملاحظات صريحة

- **الزيادة** = الحجم الآن ناقص **أصغر** حجم خلال الفترة. الزيادة البطيئة الطبيعية لا تسبب تنبيهًا.
- يظهر إشعار صغير ثابت «يراقب N فولدر» — أندرويد يشترط ذلك ليسمح للتطبيق بالعمل في الخلفية. يمكنك إخفاؤه من إعدادات إشعارات التطبيق (قناة «المراقبة المستمرة») دون إيقاف المراقبة.
- عندما تكون الشاشة مطفأة والهاتف ساكن لفترة طويلة، قد يؤخر أندرويد الفحص إلى مرة كل 10–15 دقيقة تقريبًا.
- في هواتف شاومي/هواوي/أوبو/ريلمي: فعّل **التشغيل التلقائي (Autostart)** للتطبيق، واختر «بلا قيود» في إعدادات البطارية، وإلا قد يوقفه النظام.
- لا يمكن لأي تطبيق قراءة `Android/data` و`Android/obb` على أندرويد 11 وما بعده.
- الفولدرات الضخمة جدًا (مثل الذاكرة الداخلية كاملة) قد يستغرق فحصها وقتًا وبطارية أكثر؛ اجعل «افحص كل» أطول لها.
- يعمل على أندرويد 8 فما فوق. المراقبة تستمر بعد إعادة تشغيل الهاتف.
