# منبّه الصلاة — Prayer Alarm

تطبيق أندرويد يحسب **مواقيت الصلاة** على الهاتف نفسه (بدون إنترنت) ويرنّ عند كل صلاة،
ومعه **منبّهات عادية** بتكرار حسب أيام الأسبوع.

## المميزات
- **مواقيت الصلاة** محسوبة فلكيًا حسب موقعك (GPS أو إدخال يدوي) — الافتراضي: **الهيئة المصرية العامة للمساحة**،
  ومتاح أيضًا: رابطة العالم الإسلامي، أم القرى، كراتشي، أمريكا الشمالية، الخليج. والعصر: الجمهور أو الحنفي.
- **تنبيه لكل صلاة** يمكن تشغيله أو إيقافه، عند دخول الوقت أو قبله بـ 5 إلى 30 دقيقة.
- **مجموعات منبّهات**: منبّه واحد أو عدة منبّهات متتالية (حتى 10) بفاصل تختاره، مثل 4 منبّهات كل 5 دقائق للعمل.
  عند الاستيقاظ اضغط «استيقظت» لإلغاء باقي منبّهات اليوم.
- **منبّه حسب الصلاة**: مثل «بعد الفجر بـ 5 دقائق» — يتحرك تلقائيًا مع وقت الفجر كل يوم.
- **أيام العمل والإجازة**: حدّدها مرة واحدة في الإعدادات، ثم اختر لكل منبّه: مرة واحدة، كل يوم، أيام العمل، أيام الإجازة، أو أيام محددة.
- **إشعار قبل المنبّه** (مثلًا قبله بـ 5 دقائق) مع زر «تخطٍّ»، و«تخطي القادم» من قائمة المنبّهات.
- **الإعدادات**: صوت المنبّه (نغمات الهاتف أو أي ملف صوتي)، صوت الأذان، الاهتزاز، **رفع الصوت تدريجيًا**،
  مدة الغفوة، مدة الرنين، السمة (فاتح/داكن)، وصورة خلفية لشاشة المنبّه. ويمكن اختيار صوت مختلف لكل منبّه.
- شاشة المنبّه تظهر فوق شاشة القفل، ويُعاد ضبط كل المنبّهات بعد إعادة تشغيل الهاتف أو تغيير الوقت.
- الواجهة بالعربية، وبالإنجليزية إذا كانت لغة الهاتف إنجليزية.

## صوت الأذان
من **الإعدادات ← صوت الأذان** اختر أي ملف أذان على هاتفك، ويُشغَّل مرة واحدة عند كل صلاة.
(أو ضع ملفًا باسم `adhan.mp3` داخل `app/src/main/res/raw/` قبل البناء ليكون مدمجًا في التطبيق.)
بدون ذلك تُستخدم نغمة المنبّه الافتراضية في الهاتف.

## الحصول على ملف APK
في GitHub: **Actions ← Build Prayer Alarm APK ← Run workflow**، ثم نزّل `prayer-alarm-apk`
من صفحة نتيجة التشغيل وثبّته (ستحتاج السماح بالتثبيت من مصادر غير معروفة).
يعمل تلقائيًا أيضًا عند أي تعديل في مجلد `prayer-alarm/`.

أو محليًا باستخدام Android Studio / Android SDK:
```
cd prayer-alarm
./gradlew assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest    # اختبارات حساب المواقيت
```

## ملاحظات
- المغرب = غروب الشمس الفلكي. التقويمات المصرية المطبوعة تضيف عادةً 2–3 دقائق احتياطًا،
  فقد يسبق المنبّه الموعد المطبوع بدقائق قليلة.
- على Android 14+ قد يطلب التطبيق إذن «عرض بملء الشاشة» ليظهر المنبّه على شاشة القفل،
  ويظهر في التطبيق شريط تنبيه مع زر «سماح» عند الحاجة.
- بعض الهواتف (شاومي، أوبو، هواوي…) توقف التطبيقات في الخلفية؛ اجعل التطبيق «بدون قيود» في إعدادات البطارية.

## الكود
| الملف | الوظيفة |
|---|---|
| `prayer/PrayerTimesCalculator.kt` | حساب المواقيت (خوارزمية PrayTimes.org) |
| `data/Models.kt` | مجموعات المنبّهات، الحساب حسب الصلاة، أيام العمل، والإعدادات |
| `data/Store.kt` | الحفظ (ويحوّل منبّهات الإصدار الأول تلقائيًا) |
| `alarm/AlarmScheduler.kt` | الجدولة عبر `AlarmManager.setAlarmClock` والإشعار المسبق والتخطي |
| `alarm/Receivers.kt`, `alarm/Notifications.kt` | الرنين والإشعارات وإعادة الجدولة بعد التشغيل |
| `alarm/AlarmService.kt`, `AlarmRingActivity.kt` | تشغيل الصوت (مع الرفع التدريجي) وشاشة المنبّه |
| `ui/` | الواجهة (Jetpack Compose): المواقيت، المنبّهات، محرر المنبّه، الإعدادات |
