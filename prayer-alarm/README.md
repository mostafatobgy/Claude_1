# منبّه الصلاة — Prayer Alarm

تطبيق أندرويد يحسب **مواقيت الصلاة** على الهاتف نفسه (بدون إنترنت) ويرنّ عند كل صلاة،
ومعه **منبّهات عادية** بتكرار حسب أيام الأسبوع.

## المميزات
- حساب المواقيت فلكيًا حسب موقعك (GPS أو إدخال يدوي) — الافتراضي: **الهيئة المصرية العامة للمساحة**،
  ومتاح أيضًا: رابطة العالم الإسلامي، أم القرى، كراتشي، أمريكا الشمالية، الخليج. والعصر: الجمهور أو الحنفي.
- تنبيه لكل صلاة يمكن تشغيله أو إيقافه، عند دخول الوقت أو قبله بـ 5 / 10 / 15 / 20 / 30 دقيقة.
- منبّهات عادية: مرة واحدة أو أيام محددة، مع اسم لكل منبّه.
- شاشة منبّه تظهر فوق شاشة القفل مع **غفوة 10 دقائق** و**إيقاف**، ويتوقف تلقائيًا بعد 5 دقائق.
- يعيد ضبط كل المنبّهات بعد إعادة تشغيل الهاتف أو تغيير الوقت/المنطقة الزمنية،
  ويحسب موعد الصلاة لليوم التالي بعد كل رنين.
- الواجهة بالعربية، وبالإنجليزية إذا كانت لغة الهاتف إنجليزية.

## صوت الأذان
ضع ملف أذان باسم `adhan.mp3` داخل `app/src/main/res/raw/` وسيُستخدم لتنبيهات الصلاة
(يُشغَّل مرة واحدة). بدون الملف يُستخدم صوت المنبّه الافتراضي في الهاتف.

## الحصول على ملف APK
في GitHub: **Actions ← Build Prayer Alarm APK ← Run workflow**، ثم نزّل `prayer-alarm-apk`
من صفحة نتيجة التشغيل وثبّته (ستحتاج السماح بالتثبيت من مصادر غير معروفة).
يعمل تلقائيًا أيضًا عند أي تعديل في مجلد `prayer-alarm/`.

أو محليًا باستخدام Android Studio / Android SDK:
```
cd prayer-alarm
./gradlew assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest    # اختبارات حساب المواقيت
```

## ملاحظات
- المغرب = غروب الشمس الفلكي. التقويمات المصرية المطبوعة تضيف عادةً 2–3 دقائق احتياطًا،
  فقد يسبق المنبّه الموعد المطبوع بدقائق قليلة.
- على Android 14+ قد يطلب التطبيق إذن «عرض بملء الشاشة» ليظهر المنبّه على شاشة القفل،
  ويظهر في التطبيق شريط تنبيه مع زر «سماح» عند الحاجة.
- بعض الهواتف (شاومي، أوبو، هواوي…) توقف التطبيقات في الخلفية؛ اجعل التطبيق «بدون قيود» في إعدادات البطارية.

| `ui/MainScreen.kt` | الواجهة (Jetpack Compose) |
